# Tetris

Un jeu de puzzle d’arcade jouable dans le navigateur. Déplacez et faites pivoter les pièces qui tombent pour compléter des lignes, marquer des points et éviter que la grille ne se remplisse. Le site propose aussi des modes de jeu et des thèmes visuels.

[Jouer à Tetris](https://breizhimic.github.io/Tetris/)
